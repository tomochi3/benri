調整さん 自動回答

拡張アイコンか、調整さんページに出るボタンを押すと、この設定を使って Google カレンダーから出欠を自動入力します。

Google Cloud 側で必要な設定

  1. Google Cloud で Web アプリ用の OAuth クライアントを作成します。
  2. 承認済み JavaScript 生成元に `https://chouseisan.com` を追加します。
  3. 保存後、調整さんのイベントページで拡張を実行します。

`終日` は 9:00-18:00、`19時~` のような終了時刻なし候補は 3 時間枠として判定します。
