# 調整さん 日程候補ジェネレーター

当日から n ヶ月先までの「金曜夜・土曜・日曜」の候補を自動生成し、候補入りの「調整さん」作成画面までワンタップで進めるシンプルなWebアプリです。

## 使い方
1. `index.html` をスマホ/PCのブラウザで開きます。
2. すぐ使いたいときは、上部のクイックボタン `金曜19時~/土日終日` または `金曜19時~/土日9~13時/土日13時~17時` を押します。
3. 調整さんの作成画面が候補入りで開くので、開いた先の「出欠表をつくる」を押すと共有リンクが完成します。
4. 細かく調整したいときは「詳細設定」から開始日・対象期間・金曜夜の開始時刻などを変更します。
5. 詳細設定では内容を変えるとプレビューが自動更新されるので、確認してから `この内容で調整さんを開く` を押します。

> 注: 調整さん側の初回遷移では、意図しないイベント作成防止のため確認メッセージが表示されます。候補やイベント名は入力済みの状態で開くので、そのまま「出欠表をつくる」を押せば続行できます。

## 補足
- 生成ロジック: 期間内の各日付を走査し、金曜(19:00〜・変更可) / 土曜(終日) / 日曜(終日)を候補に追加します。
- フォーマット: `M/D(曜) HH:MM〜` または `M/D(曜) 終日`。調整さんの『日程候補』欄にそのまま貼り付け可能です。
- クイック起動: 2種類のプリセットから選べます。`金曜19時~/土日終日` と `金曜19時~/土日9~13時/土日13時~17時` です。
- 端末保存: 設定（開始日・対象期間・時刻・チェック項目）はローカルに保存され、次回も引き継がれます。

## Googleカレンダー自動回答 Chrome拡張
- ファイル: `extension/`
- 対象: `https://chouseisan.com/s*` のイベントページ
- 機能: 拡張アイコンか、イベントページに出る `Googleカレンダーで自動入力` ボタンを押すと、Google Calendar の空き状況から ○ / △ / × を自動入力して送信します。

### 導入手順
1. Chrome の拡張機能ページでデベロッパーモードを有効にして、`extension/` を「パッケージ化されていない拡張機能を読み込む」で読み込みます。
2. 拡張の設定画面を開きます。
3. Google Cloud で Web 用の OAuth クライアント ID を作成します。
4. `https://chouseisan.com` を承認済みJavaScript生成元に追加します。
5. 拡張設定で OAuth クライアント ID、回答名、参照カレンダーIDを保存します。
6. 調整さんのイベントページで拡張アイコンを押すか、ページ内の `Googleカレンダーで自動入力` を押します。

### 前提とメモ
- Google Calendar は `primary` のみ参照する想定ですが、設定で複数カレンダーIDも指定できます。
- `終日` は 9:00-18:00 を広めの代表時間帯として判定します。
- `19:00〜` のような終了時刻なし候補は 3 時間枠として判定します。
- 既に同名回答があり、このブラウザで編集権限がない場合は自動更新できません。
- 拡張から直接 `window.Chouseisan` と Google Identity Services を使うため、候補の読み取りと OAuth はイベントページ上で実行しています。
