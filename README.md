# 調整さん 日程候補ジェネレーター

当日から n ヶ月先までの「金曜夜・土曜・日曜」の候補を自動生成し、候補入りの「調整さん」作成画面までワンタップで進めるシンプルなWebアプリです。

## 使い方
1. `index.html` をスマホ/PCのブラウザで開きます。
2. すぐ使いたいときは、上部の「すぐ調整さんをつくる」を押します。
3. 調整さんの作成画面が候補入りで開くので、開いた先の「出欠表をつくる」を押すと共有リンクが完成します。
4. 細かく調整したいときは「詳細設定」から開始日・対象期間・金曜夜の開始時刻などを変更します。
5. 詳細設定では「候補を生成」でプレビュー確認、「候補入りで調整さんを開く」で同じく候補入りの作成画面へ進めます。

> 注: 調整さん側の初回遷移では、意図しないイベント作成防止のため確認メッセージが表示されます。候補やイベント名は入力済みの状態で開くので、そのまま「出欠表をつくる」を押せば続行できます。

## 補足
- 生成ロジック: 期間内の各日付を走査し、金曜(19:00〜・変更可) / 土曜(終日) / 日曜(終日)を候補に追加します。
- フォーマット: `M/D(曜) HH:MM〜` または `M/D(曜) 終日`。調整さんの『日程候補』欄にそのまま貼り付け可能です。
- クイック起動: デフォルトでは「今日から2ヶ月先」「金曜19:00〜」「土日終日」「イベント名は固定文言」で調整さん作成画面を開きます。
- 端末保存: 設定（開始日・対象期間・時刻・チェック項目）はローカルに保存され、次回も引き継がれます。
